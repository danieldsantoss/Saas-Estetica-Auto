# Sistema SaaS para Estética Automotiva

Sistema web desenvolvido para auxiliar no gerenciamento de estéticas automotivas, permitindo controle de clientes, serviços e orçamentos em um único painel.

## Tecnologias utilizadas

* Python
* Flask
* SQLite
* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Login administrativo
* Cadastro de clientes
* Cadastro de serviços
* Dashboard do sistema
* Controle de orçamentos
* Relatórios
* Upload de logo
* Tema claro e escuro
* Interface responsiva

## Objetivo do projeto

Este projeto foi desenvolvido para praticar desenvolvimento web full stack utilizando Flask, SQLite e JavaScript.

O objetivo foi criar um sistema mais próximo de uma aplicação real utilizada por empresas.
